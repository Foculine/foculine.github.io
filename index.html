The 20-Minute QA Challenge: test an online store like a real QA tester

Never tested software before? In about 20 minutes you will read requirements, run test cases on a practice store, record your results and try to find a hidden problem. Built for complete beginners who are curious about manual QA.

What you will learn

Five core manual-testing skills, practised in one short session.

1

Understand basic requirements

Read a short requirements excerpt and turn it into things you can check.

2

Run test cases

Follow written steps exactly and compare what happens with the expected result.

3

Record test results

Note what you really saw, mark Pass or Fail, and keep your evidence.

4

Identify a software defect

Spot when the store does not behave the way its requirements say it should.

5

Write a basic bug report

Describe a problem clearly enough that someone else could reproduce it.

What's included

Everything is in one small download. Nothing to install apart from Python 3.

PDF guide

A 10-page, step-by-step guide: what manual testing is, how to start, and how to work through the challenge.

Practice store

Northstar Market, a fictional online store that runs in your own browser. No accounts, payments or real data.

Test cases and scenarios

Three fully written test cases (positive and negative) and five scenarios for search and category filtering.

Editable results sheet

A simple spreadsheet for results, status, notes and evidence. It works in Excel, LibreOffice or Google Sheets.

Bug-report exercise

A clear structure for reporting a defect, plus a worked example from a different app. There is no answer sheet.

Who it is for

If you want to find out what manual testing feels like before you commit to learning it, start here.

  • ✓Complete beginners. No testing or coding experience needed.
  • ✓People learning manual QA who want a hands-on exercise.
  • ✓People who want practical experience before applying for junior QA positions.
Please note: this is simulated, self-directed practice. It is not professional work experience and it is not a certification. It does not promise a job or an interview.

How it works

Four steps, about 20 minutes.

1

Download the files

Get the free ZIP and unzip it to a folder.

2

Start the practice store

Run one command in a terminal, then open the store in Chrome or Edge.

3

Follow the guide

Read the requirements excerpt and the test scenarios in the PDF.

4

Complete the exercises

Run the test cases, fill in the results sheet and write a bug report if something fails.
